# Данные

Изображения DeepWeeds в репозиторий не кладём (их тысячи, это не код).

1. Скачайте набор DeepWeeds: репозиторий авторов https://github.com/AlexOlsen/DeepWeeds (ссылки на изображения в README)
   или готовую копию на Kaggle.
2. Распакуйте так, чтобы в одной папке лежали все `*.jpg` и файл `labels.csv`
   (столбцы `Filename`, `Label`, `Species`; метки 0-7 - виды сорняков, 8 - «не сорняк»).
3. Путь к этой папке передавайте скриптам через `--data_dir`.

Если картинки лежат по подпапкам классов (формат ImageFolder), код тоже это понимает.
