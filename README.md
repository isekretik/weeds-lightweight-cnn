# Сравнение лёгких свёрточных сетей для распознавания сорняков (DeepWeeds)

Практическая часть курсового проекта по дисциплине «Технология обработки больших данных ИИ»
(направление «Анализ изображений и видео»).

**Задача.** Выбрать нейросеть, которую можно поставить на агродрон или полевой робот: достаточно точную
и достаточно лёгкую и быструю. Сравниваются ResNet-50 (базовая модель), ResNet-18, MobileNetV3-Small,
MobileNetV3-Large и EfficientNet-B0 на наборе [DeepWeeds](https://github.com/AlexOlsen/DeepWeeds)
(17 509 изображений, 8 видов сорняков и класс «не сорняк»).

## Что считается
- качество: accuracy и macro-F1, среднее ± разброс по 3 seed, матрица ошибок;
- ресурсы: число параметров, размер модели, GFLOPs, задержка на кадр (CPU и GPU);
- устойчивость: падение macro-F1 при размытии, шуме и изменении яркости;
- объяснимость: карты Grad-CAM;
- блок «большие данные»: распределение классов, скорость загрузки данных при разном числе процессов;
- (необязательно) экспорт в ONNX и квантование INT8.

## Структура
```
src/        код: common, train, benchmark, robustness, gradcam, export_onnx, loader_throughput, aggregate
scripts/    run_all.sh (весь эксперимент), make_synthetic.py (игрушечные данные для проверки кода)
notebooks/  colab_run.ipynb - запуск на Colab/Kaggle по шагам
data/       как получить DeepWeeds (сами изображения не коммитятся)
results/    таблицы, графики и metrics.json запусков (веса *.pt не коммитятся)
report/     пояснительная записка и презентация
```

## Быстрый старт
```bash
pip install -r requirements.txt

# 1. проверка кода на игрушечных данных (без интернета; цифры ничего не значат)
python scripts/make_synthetic.py --out toy_data
python src/train.py --data_dir toy_data --model mobilenet_v3_small --epochs 2 --workers 0 --no_pretrained

# 2. настоящий эксперимент (нужны данные DeepWeeds и желательно GPU)
bash scripts/run_all.sh /путь/к/DeepWeeds
```
Результаты появятся в `results/`: `table_main.csv`, `table_robustness.csv`, рисунки `fig_*.png`,
`<модель>_s<seed>/metrics.json`.

## Методика (кратко)
- Разбиение train/val/test = 60/20/20, стратифицированное, фиксировано (seed 0) и одинаково для всех моделей.
- Перенос обучения с ImageNet: последний слой заменяется на 9 выходов, основа 2 эпохи заморожена, затем дообучается.
- AdamW, косинусное расписание, ранняя остановка по macro-F1 на val; тест используется один раз в конце.
- Скорость: batch 1, 20 прогревочных и 100 замеров, берётся медиана.
